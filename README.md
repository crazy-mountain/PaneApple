# PaneApple

Window snapping, without the fuss.

Drag a window to a screen edge to see a preview, then release to snap it into place.

## Download

[Download the signed PaneApple beta](https://github.com/crazy-mountain/PaneApple/releases/tag/v0.2.0-beta.1). Requires Apple Silicon and macOS 14 or later.

Open the disk image, drag PaneApple to Applications, then open it from Applications. Click Enable in PaneApple and grant Accessibility permission when macOS asks so PaneApple can move windows.
